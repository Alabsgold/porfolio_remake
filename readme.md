# Portfolio

A Modern, responsive perosnal debeloper website built with
**Next.js**, **Typescript** and **Tailwind CSS**.
This Repostiory houses my source code for my portfoliio site, designed to
showcase my skills, projects, and professional background.

## About

This project represents my **professional developer portfolio website**. It
is built to be:

- Fast and SEO-friendly using Next.js (React framework)
- Fully responsive across devices
- Styled with Tailwind CSS for utility-first design
- Typed with typescript for enhanced developer experience
  
The site higlight my work, skills, contact information and other relevant developer acheivements.

## Installation

To run this locally:

1 **Clone the repository**

```bash
   git clone <https://github.com/Alabsgold/porfolio_remake.git>
   cd porflio_remake
```

2 **Install Dependencies**

```bash
    npm install
    #or
    yarn install
```

3 **Run locally**

```bash
    npm run dev
```

The develoopment Server will run at <http://localhost:3000>

## Build and Deployement

To create an optimized production build

```bash
    npm run build
```

```bash
    npm start
```
